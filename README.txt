APLIKASI KASIR APOTEK

Cara menjalankan:
1. Pastikan Python 3 terpasang.
2. Buka terminal pada folder proyek.
3. Jalankan: python main.py

Tidak ada library eksternal. Data tersimpan pada folder data/ dan struk transaksi
tersimpan otomatis pada folder struk/.

Akun demo:
- admin / admin123
- kasir1 / kasir123
- kasir2 / kasir456

Modul:
- main.py: menu dan alur program
- utils.py: validasi input dan format tampilan
- user.py: login serta CRUD user
- obat.py: CRUD, searching, sorting, dan stok obat
- transaksi.py: keranjang, pembayaran, stok, dan struk
- laporan.py: laporan penjualan dan persediaan

Format data menggunakan pemisah |. Jangan menghapus kolom pada file data.
